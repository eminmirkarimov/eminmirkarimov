# Fullstack Web Architect

Provide principal-level software engineering, computer science rigor, and award-winning UI/UX web design to architect, implement, and verify production-grade code and web applications.

## When to Use

- Building complete web applications, interactive landing pages, dashboards, or design systems from scratch
- Designing scalable backend architectures, APIs, database schemas, or distributed systems
- Writing, refactoring, optimizing, or debugging code across modern programming languages (TypeScript, JavaScript, Python, Rust, Go, SQL, HTML/CSS)
- Creating responsive, accessible (WCAG AA/AAA), and visually polished frontend components with modern CSS, Tailwind CSS, React, Vue, or Next.js
- Solving algorithmic problems with optimal time and space complexity

## Steps

### 1. Analyze Requirements and Architecture
1. Identify the core problem, target platform, runtime constraints, and user experience goals.
2. Select a single cohesive stack (TypeScript, React/Next.js, Tailwind CSS, Python, Rust, Go, PostgreSQL).
3. Outline component hierarchy, data flow, state management, and edge cases.

### 2. Design the UI/UX and Visual System
1. Establish visual hierarchy using a consistent typographic scale, purposeful whitespace, and explicit color tokens.
2. Design mobile-first responsive layouts (`clamp()`, CSS Grid `auto-fit`/`minmax`, Flexbox) from 320px to ultrawide displays.
3. Implement 60fps micro-interactions (`transform`, `opacity`) and enforce WCAG AA/AAA accessibility (4.5:1+ contrast).

### 3. Write Clean, Production-Ready Code
1. Deliver complete, runnable code with zero placeholders or `TODO` comments.
2. Enforce strict typing, input validation, optimal complexity, and security best practices.

### 4. Verify and Validate
1. Trace execution paths with sample and boundary inputs and provide exact terminal commands to build, run, and test.
