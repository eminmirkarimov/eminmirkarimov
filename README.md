## ⚡ Быстрая установка (Quick Installation)

### 1. Через терминал одной командой (`npx skills`)
Установите весь пакет скиллов в **Claude Code, OpenAI Codex CLI, Cursor или Windsurf**:
```bash
npx skills add https://github.com/eminmirkarimov/emin-mirkarimov-genius
```
Или установите конкретный скилл из каталога `skills/`:
```bash
npx skills add https://github.com/eminmirkarimov/emin-mirkarimov-genius --skill emin-mirkarimov-genius
npx skills add https://github.com/eminmirkarimov/emin-mirkarimov-genius --skill emin-mirkarimov-omni
npx skills add https://github.com/eminmirkarimov/emin-mirkarimov-genius --skill emin-mirkarimov-beauty-health
npx skills add https://github.com/eminmirkarimov/emin-mirkarimov-genius --skill sovereign-omni-creator
npx skills add https://github.com/eminmirkarimov/emin-mirkarimov-genius --skill omni-creative-architect
npx skills add https://github.com/eminmirkarimov/emin-mirkarimov-genius --skill fullstack-web-architect
```

### 2. В OpenAI Codex / Cursor / Windsurf (Авто-подхват через `AGENTS.md`)
Файл [`AGENTS.md`](./AGENTS.md) уже лежит в корне этого репозитория — при открытии проекта агент автоматически загружает все стандарты архитектуры, дизайна и продакшна.

### 3. В ChatGPT (Custom GPTs / Projects), Gemini (Gems) и Claude.ai
- **ChatGPT & Gemini:** Скопируйте содержимое [`SKILL.md`](./SKILL.md) в поле **Instructions / System Instructions**, а файлы из папки [`references/`](./references/) прикрепите в **Knowledge**.
- **Claude.ai (Web):** Загрузите архив репозитория в `Settings → Capabilities → Skills`.

## 🛠 Как использовать встроенные скрипты (`scripts/`)

### 1. Генерация голливудского 3D LUT (`.cube`) для DaVinci Resolve / Premiere / CapCut
```bash
python3 scripts/generate_emin_genius_lut.py
```
Скрипт создает математически выверенный файл **`emin_genius_2383.cube`** (размер решетки `33x33x33`) с S-кривой контраста, мягким ролл-оффом светов и пленочным сплит-тонингом **Kodak 2383**.

### 2. Авто-сборка 4K 24fps сцены и света в Adobe After Effects (`.jsx`)
Откройте **Adobe After Effects** → перейдите в `File → Scripts → Run Script File...` и выберите **`scripts/emin_after_effects_master.jsx`**. Скрипт автоматически создаст мастер-композицию `3840x2160` (`24fps`, угол затвора `180°`), обсидиановый фон *The Dark Room* (`#090A0C`), 3D-титр с выражением инерционной пружины, 3D-свет по схеме Дикинса/Фрейзера (`3200K` Key + `5600K` Rim) и 50-мм камеру ARRI.
